# talent-lab - AI 赋能的简历分析与求职机会管理平台

## 背景
个人求职过程中往往需要维护多版简历、反复整理职位描述、判断匹配度，并在多个渠道之间跟踪申请进展。
talent-lab 将 PDF 简历解析、职位机会管理、AI 匹配分析和申请时间线集中到一个受访问密钥保护的工作台中，同时保留简历筛选、比较和可视化能力。

## 技术栈
- 前端框架：Vite + TypeScript + React
- 前端状态：TanStack Query + Zustand
- 国际化：i18next（中文 / 英文）
- 后端语言：Python + Flask
- 数据存储：SQLite + SQLAlchemy
- API 规范：RESTful + SSE

## 模块

### 模块一：简历上传与解析
- 提供文件上传组件，支持 **拖拽上传** 和 **点击上传**，限制 PDF 格式
- 支持 **批量上传**（单次最多 5 份简历），展示上传进度和状态
- 后端解析 **PDF** 内容，提取文本信息（需兼容多页简历）
- 对提取文本进行清洗和结构化处理

### 模块二：AI 智能信息提取
利用 AI 模型（如 OpenAI API）从简历文本中提取以下结构化信息：

| 类别 | 字段 |
| --- | ----------- |
| 基本信息 | 姓名、电话、邮箱、所在城市 |
| 教育背景 | 学校、专业、学历、毕业时间 |
| 工作经历 | 公司名称、职位、时间段、工作内容摘要 |
| 技能标签 | 技术栈、工具、语言等（以标签形式提取） |
| 项目经历 | 项目名称、技术栈、个人职责、项目亮点 |

- AI 提取过程通过 **SSE（Server-Sent Events）** 流式返回，前端逐步渲染提取结果
- 支持用户在前端手动修正 AI 提取的信息

### 模块三：职位机会、申请追踪与智能匹配
- 面向个人求职者保存职位机会：来源、JD 原文、结构化职责与要求、薪酬、联系人和个人判断
- 粘贴 JD 后提取公司、职位、地点、经验、学历、技能和薪资；解析结果确认后再应用
- 支持按关键字和申请状态筛选职位机会，并可标记收藏与优先级
- 每个职位可匹配多份简历，并记录实际投递的简历版本
- 保存从未申请、准备、已投递到笔试、面试、Offer、接受 / 拒绝 / 撤回的当前状态和完整时间线
- 支持补录笔试、面试、Offer、备注和待办，并记录下一步行动
- 调用 AI 模型对简历与职位要求进行匹配分析，返回：
  - **综合匹配度评分** （0-100 分）
  - **各维度子评分：** 技能匹配度、经验相关性、教育背景契合度
  - **AI 评语与洞察：** 匹配优势、技能缺口和简历定制建议
- 评分结果以 **可视化图表** 展示（如雷达图 / 柱状图 / 环形进度条）
- 支持多个 JD 同时对比评分

### 模块四：候选人管理面板
- 实现候选人列表页，支持： 
  - **表格视图 / 卡片视图** 切换
  - 持久化不同视图的每页数量与最近使用的视图
  - 按评分、上传时间、技能标签 **排序与筛选**
  - 关键字搜索（姓名、技能、学校等）
  - 分页浏览
- 点击候选人进入 **详情页**，展示完整的解析信息、评分详情、原始 PDF 预览
- 支持候选人状态管理（待筛选 → 初筛通过 → 面试中 → 已录用 / 已淘汰），状态变更需有视觉反馈
- 支持候选人对比功能（选择 2-3 人，并排对比各维度评分）

### 模块五：前端工程质量
- 使用 **组件化架构** ，合理拆分组件粒度，体现复用性和可维护性
- 页面整体需具备 **良好的视觉设计和交互体验**（不接受纯原生 HTML 样式）
- 实现 **响应式布局**，适配桌面端（≥1280px）
- 全局错误处理与 Loading 状态管理
- 提供中文 / 英文界面，自动检测浏览器语言并保存手动选择
- 页面按路由懒加载，并提供统一的路由加载反馈
- 支持暗色 / 亮色主题切换、骨架屏加载态、键盘快捷键和动画过渡
